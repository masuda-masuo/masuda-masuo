## 🛠️ Project Portfolio

AIエージェントの能力を安全に200%引き出すための、自作MCPサーバーおよび自律開発基盤のポートフォリオです。

### 1. [sunaba (砂場)](https://github.com/masuda-masuo/sunaba) 🏜️
> **AIエージェント専用の強固な隔離サンドボックス ＆ 検証ゲートMCP**

*   **概要**: AIエージェントが安全にコマンドを実行し、ファイルを編集するためのDockerコンテナ隔離スペース。開発の test → verify → publish ループを、使い捨てのコンテナの中で丸ごと回します。
*   **検証ゲート**: AIが提案するコード変更に対し、lint（ruff）・型チェック・テスト（pytest）を完全にパスしない限り提出（publish）を認めない「検証ゲート」をインフラ側で強制します。AIの自爆やバグ混入を物理的にブロックします。
*   **境界を守る**: 「危険なコマンド」をフィルタする方式は採りません。守るのは**サンドボックスの境界**だけです。デフォルト拒否の Egress Proxy で外向き通信を絞り、VCSトークンは常にホスト側に留まり**コンテナには一切渡りません**（唯一のネットワーク出口が `publish`）。
*   **ペイロードをLLMに通さない**: Issue本文・ソース・差分・生ログといった重いデータはコンテナ内で生まれてコンテナ内で死に、モデルが運ぶのは `run_id` とハンドル、構造化サマリだけ。テスト失敗は5000行のログではなく `{test, error, file, line}` で返ります。
*   **AX設計**: AIのパニックループを止める「Undoタイムマシン（`undo_file_edit`）」、トークン不要の軽量セーブポイント（`checkpoint`）などを標準装備。systemd 常駐サービスとして動かす前提の設計です。

### 2. [shiori (栞)](https://github.com/masuda-masuo/shiori) 🔖
> **ドキュメント・コード・Issue/PR議論を単一索引で横断する、ポインタ返却型の知識検索MCP**

*   **概要**: AIエージェントがソースコードやドキュメント（What / How）だけでなく、過去の Issue や PR の議論ログ（**Why** — なぜその設計になったか、何が却下されたか）を横断的に探索するためのローカル検索サーバー。
*   **RAGではない**: 回答を生成せず、コンテキストへの自動注入もしません。返すのは**座標とスニペット（ポインタ）だけ**で、全文を読むかどうかはエージェントが決める **Pointer-then-Fetch** モデル。ファイル丸読みによるコンテキスト破壊を防ぎます。
*   **境界を越えて辿れる**: ヒットしたIssue → それを解決したPR → 変更されたファイル → 設計文書、と検索結果から連鎖的に辿れます。日本語のクエリで英語のIssueが引ける**クロスリンガル**検索。
*   **アーキテクチャ**: GitHub APIの中継プロキシではなく、ローカルの PostgreSQL（`pgvector` + `pgroonga`）と Shallow Clone によるローカルデータストアを構築。ベクトル検索とキーワード検索を RRF でハイブリッド融合し、埋め込みモデルもローカルで動かすため**完全オフライン**かつ高速に機能します。
*   人間向けのブラウザダッシュボードを MCP と同じポートに同梱しています。

### 3. [kusabi (楔)](https://github.com/masuda-masuo/kusabi) 🪓
> **AI自律開発のための委譲オーケストレーション ＆ コンテキストファイアウォール**

*   **概要**: Claude Code から重い実装タスクや敵対レビューをワーカーバックエンド（既定は [opencode](https://opencode.ai)、`--backend claude` でヘッドレスな Claude Code CLI）へ委譲するための基盤。
*   **コンテキストファイアウォール**: 委譲の本質的な価値は「安い」ことより、**ワーカーの中間出力が親のコンテキストを焼かない**ことにあります。ワーカーのナレーション・ツールログ・生イベントはすべてローカルの状態ディレクトリに永続化され、親モデルには**レンダリング済みの最終結果だけ**が返ります。
*   **自動チェーン**: 実装担当モデルのコード変更に対し、**別セッションの独立したレビューエージェント**による敵対レビューを自動でループさせ、受理か打ち切りまで「**実装 ➔ レビュー ➔ 差し戻し**」を往復させます（`chain`）。ラウンドが進むごとにモデル階層を上げる段階的エスカレーションを持ちます。
*   **経済的打ち切り**: テストが全緑で残る指摘が軽微なら、そこでループを打ち切って合格とし、残作業をフォローアップIssueの下書きへ繰り延べます。早期終了の悪用は、独立レビュー・機械テストの絶対性・Issueの可視化という多重ゲートで抑えます。
*   **AX設計**: ワーカーがクラッシュやタイムアウトで死んだ際に直前のログから事故原因を自動調査する「**自律サルベージ（`salvage`）**」、実装セッションからホスト側の書き込みツールを構造的に剥奪するフェーズ別のパーミッション制御を装備。
